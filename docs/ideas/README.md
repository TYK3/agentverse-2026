# Ideas

All the ideation behind the project, newest first. These are options, not decisions: anything marked
**Open** is for the team to settle, and settled choices go in the decisions log in `coord/CONTEXT.md`.
The track brief and judging weights are in `docs/brief.md`.

| File | What it is | Status |

| [search-rescue-rover.md](search-rescue-rover.md) | Autonomous search and rescue rover: sensors, 3D SLAM, talking to victims, simple tasks, layered decision making, demo ideas | **Current direction** |
| [novelty-and-more-ideas.md](novelty-and-more-ideas.md) | Novelty check, six more robotics ideas (incident commander, sniffer, and others) and the problem each solves | Background |
| [first-responder-robot.md](first-responder-robot.md) | First version: a robot that finds a casualty, fetches first aid items and coaches a bystander; scored against the judging | Superseded (about 85, weak on novelty) |

What carries into the rescue rover from the earlier ideas: two clues before declaring a find,
"possible" instead of overclaiming when unsure, the handover report, and judges changing the world
mid-run.
